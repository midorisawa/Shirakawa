# Shirakawa プライバシーポリシー

最終更新日：2026年9月23日

Shirakawa（以下「本拡張機能」という）は、Xの投稿本文を利用者が設定した条件に基づいて判定し、タイムライン上の表示を調整するブラウザ拡張機能です。

## 外部に送信される情報

本拡張機能は、Xの投稿本文と利用者が設定した条件との適合度を判定するため、以下の情報を外部へ送信します。

- Xの投稿本文：`x.com`のページ上に表示される投稿の本文
- 判定条件：投稿の表示・非表示の判定に使用するための、利用者が設定した条件
- APIキー：利用者が入力したTypeSafeまたはOpenRouterのAPIキー
- 判定に使用するモデル：判定に使用するために利用者が選択・指定したAIモデル

これらの情報は、利用者が選択した外部サービス（次項参照）へブラウザから直接送信されます。本拡張機能の開発者へ送信されることはありません。

## 外部サービスとの連携

本拡張機能では、判定処理を行うAIサービスとして次のいずれかを使用できます。

- TypeSafe API：TypeSafe AI社の提供するサービス
- OpenRouter API：OpenRouter社の提供するサービス。選択したモデルの提供事業者（例：Jevの場合はTypeSafe AI社など）へリクエスト情報を送信します。

外部サービスへ送信された情報の取り扱いは、各サービス事業者およびモデル提供事業者のポリシーに従います。
- [TypeSafe AI プライバシーポリシー](https://typesafe.ai/legal/privacy-policy)
- [OpenRouter プライバシーポリシー](https://openrouter.ai/privacy/)

## ブラウザ内に保存される情報

本拡張機能は、設定の保持、重複リクエストの防止、および利用状況の表示・管理のため、次のデータをブラウザ内に保存します。

- 利用者が設定した各種情報（APIキーを含む）
- 判定済みの投稿の投稿IDおよび判定結果
- 消費トークン数などの利用量情報

利用者は、設定画面から保存データの変更・削除や利用量のリセットをいつでも行えます。また、ブラウザから本拡張機能を削除すると、保存されていたすべてのデータがブラウザ上から完全に削除されます。
